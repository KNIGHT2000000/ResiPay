<objective>
**As a** fintech operations team,  
**I want to** enforce a strict payment state transition machine with first-class UNKNOWN state handling,  
**so that** illegal transitions are rejected and network timeouts never erroneously mark transactions as failed.

Purpose: Guarantee transactional consistency across payment lifecycles and eliminate double-capture vulnerabilities resulting from premature failure assumptions.
Output: PaymentStateMachine, transition validation tests, PaymentService, PaymentController, and timeout integration tests.
</objective>
